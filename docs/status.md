# Current status

Current status is generated from PyPI and GitHub evidence. Run:

```bash
uv run ml4t-ecosystem collect
```

The generated local files are `status/current.json` and `status/current.md`. They are not edited by
hand. Dated qualification snapshots are tracked under `status/snapshots/` after validation.

The initial seven-library qualification is in progress. See `reviews/` for dated findings.
